# DCAP Tool — Data Cleaning Automation Project
This project is part of the NCLab Python Developer Training Program and supports my transition into a future data analytics career by giving me hands-on experience with Python, pandas, and basic data preprocessing workflows.
#### -- Project Status: Completed
## Project Intro/Objective
The purpose of this project is to create a simple, user-friendly data cleaning tool that automates common preprocessing tasks such as removing missing values, renaming columns, filtering data, and exporting cleaned results. This project demonstrates how Python and pandas can streamline repetitive data tasks and prepare datasets for analysis. It also serves as a foundational step toward building more advanced analytics tools in the future.

## Project Description
This project allows users to upload a CSV file through a Flask web interface. The backend uses pandas to load and inspect the dataset, drop missing values, rename columns, filter rows, and export cleaned data to a new file.
### Challenges Faced
I had **limited exposure to pandas prior to this project**. NCLab introduced pandas briefly, but this was my first time applying it in a full project. Learning how DataFrames work, how to index and transform data, and how to connect pandas logic to a Flask interface was challenging at first. Working through these challenges helped me build confidence and gave me practical experience with tools I will use in my future data analytics career.
